2D MODULAR GROUND KIT
v1.0.0
Created in Unity 6.2

Thank you for downloading the 2D Modular Ground Kit.

This free environment pack is designed to provide a flexible pixel-art foundation for 2D RPGs, cozy games, adventure games, prototypes, and other tilemap-based projects.

INCLUDED CONTENT
- Grass environment tiles
- Dry grassland environment tiles
- Snow / northern environment tiles
- Desert environment tiles
- Beach environment tiles
- Corrupted-land environment tiles
- Dirt paths and path pieces
- Water and shoreline tiles
- Natural borders and environmental details
- Props and decorative assets
- Tile Palette for quick painting
- Sample scene demonstrating the pack
- Animated water system
- Animated shoreline / wave system
- Procedural biome blending system
- Demo ambience, camera tour, and cozy scene details

IMPORTANT: MASTER SPRITESHEET SOURCE FILE
The package includes the master GIMP .xcf file used to build the primary spritesheet.

The .xcf keeps grass, paths, terrain elements, and other source artwork separated onto individual layers. This means you are not limited to the combinations exported with the pack. You can open the source file in GIMP and create additional combinations or edits for your own project.

The included sprite artwork was created in GIMP.

HUMAN-MADE ASSETS
All included assets are human-made. We are proud to provide artwork and supporting content created by people rather than generated art assets.

UNITY / RENDERING
This release was created in Unity 6.2.

The supplied shoreline shaders and some demo effects use the Universal Render Pipeline 2D lighting system. For the sample scene and the supplied shoreline look, use a URP 2D project.

AUDIO SAMPLES
The Demo/Audio folder contains sample sound effects from Timbeaux's 2D Fantasy SFX Pack, a separate free asset pack. At the time this package was prepared, that separate SFX pack was still pending Unity Asset Store approval.

The audio samples are included to demonstrate ambience and camera-stop sound playback in the sample scene.

WHERE TO START
1. Open the included sample scene.
2. Review the Tile Palette and supplied terrain pieces.
3. Read Quick_Setup_Guide.txt for the fastest setup path.
4. Read 2D_Modular_Ground_Kit_Full_Documentation.pdf for complete setup and technical information.

PACKAGE ORGANIZATION

    Main artwork, source art, tiles, props, and Tile Palettes.

Runtime/
